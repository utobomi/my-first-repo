# 프로젝트 제목

## 1. 프로젝트 개요
이 프로젝트는 CLI, Docker, Git/GitHub의 기본 사용법을 실습하고,
Dockerfile을 작성하여 컨테이너 환경에서 애플리케이션을 실행한 뒤,
그 결과를 GitHub 저장소에 정리하는 것을 목표로 한다.

주요 목표는 다음과 같다.

- 터미널에서 기본 명령어 사용
- Docker 이미지 빌드 및 컨테이너 실행
- Dockerfile 작성
- 포트와 볼륨 개념 실습
- Git을 이용한 버전 관리
- GitHub 저장소를 통한 산출물 제출
